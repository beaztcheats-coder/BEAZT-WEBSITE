Prerequisites

  • Windows 10 / 11 64-bit with the latest updates installed.
  • An active license key — find it on the My Keys page after purchase.
  • RivaTuner Statistics Server (required for the overlay) — see Downloads below.
  • Administrator access on your PC — right-click the loader and choose Run as administrator.
  • A stable Rust install and a reboot after any driver or Windows update.

Disable real-time protection first

Windows Defender and most antivirus software flag game loaders as false positives. Temporarily turn off real-time protection before downloading and running the loader, then re-enable it afterwards. Path: Settings → Privacy & Security → Virus & Threat Protection → Manage Settings.

Keys appear on My Keys

Keys land on the My Keys page once payment completes — usually within minutes. Copy the key from your key card and paste it into the loader to activate. Never share your key.

Step-by-step setup

  1. Get your loader

    Loaders are attached to each product. After purchasing{% if product %} {{ product.name }}{% endif %}, download the loader from the My Keys page — it appears on your key card{% if loader_href %} (or use the direct download above){% endif %}.

    Go to My Keys {% if not current_user.is_authenticated %} Sign in {% endif %}

  2. Install RivaTuner Statistics Server

    Required for the overlay to function correctly. Install the latest version from the official mirror and keep default settings unless support tells you otherwise.

    Download RivaTuner

  3. Disable antivirus real-time protection

    Windows Defender and most antivirus software will flag game cheats as false positives. Temporarily disable real-time protection before downloading and running the loader.

    Windows Defender: Settings → Privacy & Security → Virus & Threat Protection → Manage Settings → Turn off Real-time Protection

  4. Run the loader as administrator

    Extract the loader anywhere except system folders, right-click it, and choose Run as administrator. Keep RivaTuner installed with default settings while the loader starts.

  5. Enter your license key

    After purchasing a license, find your key on the My Keys page. Copy it and paste it into the loader to activate. Keys are case-sensitive — copy, don't retype.

    Go to My Keys {% if not current_user.is_authenticated %} Sign in {% endif %}

  6. Launch Rust and verify the overlay

    Start Rust after the loader reports success. If the overlay does not appear, reboot, re-run as administrator, and ask operators in Discord with a screenshot of the loader window.

    Get help in Discord Read the FAQ
